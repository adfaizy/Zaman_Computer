# Zaman Computer

Premium Computer & Laptop Store — **Zaman Computer**, Gulberg Town, Raiwind, Lahore.

**Your Trusted Technology Partner** — quality computers, laptops, accessories & repair services at the best prices in Pakistan.

**Live site:** https://adfaizy.github.io/Zaman_Computer/

## Features

- Premium black & gold single-page site — pure HTML / CSS / Vanilla JS, zero frameworks, zero build tools
- 65-product catalog with search + category filter (Desktops, Laptops, Accessories, Hardware, CCTV & Security)
- Services & prices list (Windows, repair, data recovery, custom PC building…)
- Appointment booking via WhatsApp
- **Invoice & QR Center** — create invoices, print/PDF/send via WhatsApp, auto Code-39/QR verify
- Owner price manager (daily Lahore market rates)
- Installable **PWA** (`manifest.json` + `sw.js` — works offline)

## Tech

Static site. No dependencies. Deployed on GitHub Pages.
